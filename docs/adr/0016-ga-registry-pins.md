# GA registry pins for the V2 plugin API

Supersedes ADR-0010. The V2 plugin API left beta: stock hosts are GA (`opencode` v2.0.9+) and the plugin packages moved from the `@opencode-ai/*` beta line to the `@opencode/*` GA line. We migrated the plugin to registry pins — `@opencode/plugin@2.0.10` + `@opencode/schema@2.0.10` (exact, latest at migration time) — deleted the `file:./vendor` checkout, and moved the Effect import from `@opencode-ai/plugin/v2/effect` to `@opencode/plugin/effect` (`Plugin.define`, namespace import — `define` is not a top-level export there).

**Considered options**: staying on the beta line (rejected — unpublishable `file:` dep, stale `next-17444` schema, and the beta host line is frozen while stock hosts moved to GA); pinning to the installed host's exact version 2.0.9 instead of latest 2.0.10 (rejected — 2.0.10 is a patch bump on the same API, and the repo policy is latest-at-migration with exact pins); bumping `effect` to latest stable 3.22.2 (rejected — `@opencode/plugin` declares `effect@4.0.0-rc.112`, and tool-input decode couples our Schema AST to the plugin's effect build, so `effect` stays exactly on the plugin-declared rc); rewriting tools against `Schema.discriminatedUnion` now that the beta breakage may be fixed (rejected — the `Schema.Union` form from ADR-0010 typechecks and passes all 255 unit tests plus the 4-format tracer on rc.112; churn with no symptom is not a migration task).

**Consequences**: breaking release (same surface as ADR-0010's V1→V2 break — consumers on old hosts must upgrade together); `ctx.invoke` remains custom-host-only (GA `Context` has no `invoke` domain — the `LiveCtx` feature-detect in `src/plugin/index.ts` keeps that branch for the host UI while stock hosts take the `ctx.tool` path); `options: { codemode: false }` and same-name builtin replacement (`edit`) re-verified by typecheck against the GA `Tool.Info`/`ToolDomain` types, full host-decode proof still requires a live agent run (tracer covers in-process decode; `run-isolated.sh` is the documented manual path); Dependabot `ignore` entries move to the new coupled names (`effect`, `@opencode/schema`); the isolated runtime CLI tracks the beta tag's latest (`beta-19271`).
